# Крутящий Момент

Русскоязычный адаптивный сайт вымышленного автосервиса для портфолио. Тёмный индустриальный дизайн, оранжевые акценты, валюта — рубли. Без сборки и без npm-зависимостей.

## Запуск

Node.js 22+: `npm run dev`, затем http://127.0.0.1:4173. Проверки: `npm run check` и `npm test`.

## Возможности

- 8 услуг с редактируемыми ценами, калькулятор марки/модели/года/проблемы/услуги.
- Запись с валидацией и свободными интервалами, описание симптомов.
- Статус ремонта по номеру заявки; пример KM-1042.
- `/admin.html`: заявки, изменение статуса, история, цены, добавление/удаление услуг, расписание, автомобили клиентов, экспорт CSV.
- Состояния загрузки, ошибки хранилища, адаптивность, доступные формы, поддержка reduced motion.

## Демонстрационный режим

Данные сохраняются в localStorage текущего браузера. Админ-панель публичная и демонстрационная. Это **не** защищённая производственная CRM, запись не бронирует реальный пост и не отправляет данные мастеру. Сайт не содержит реальных контактов; отзывы вымышленные и отмечены как примеры. Фото иллюстративные (Unsplash), карта — OpenStreetMap. Расписание демонстрирует один пост. Данные не синхронизируются между устройствами. Не вводите настоящие персональные данные.

## Архитектура

`public/data.js` — каталог, расчёт и валидация. `public/store.js` — репозиторий демо-данных. `public/app.js` — публичные формы и интерактивность. `public/admin.js` — администрирование. `api/lead.js` — отключённый по умолчанию серверный обработчик Telegram. `scripts/serve.mjs` — локальный сервер. Vercel обслуживает `public/` и серверную функцию.

## Telegram и переход к реальному сервису

Обработчик `/api/lead` требует секретов `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `ALLOWED_ORIGIN` в настройках Vercel. Секреты не помещаются в клиентский код. Демонстрационные формы намеренно не вызывают этот обработчик. Перед их переключением добавьте серверную базу, атомарное бронирование, авторизацию администратора, распределённое ограничение запросов и защиту от спама; после сохранения заявки подключите вызов уведомления. Также необходимо добавить реальные реквизиты оператора данных, документы и контакты. Это отдельная производственная настройка, не часть демонстрационного режима.

## Публикация

GitHub хранит исходники. Vercel: Framework Preset Other, Output Directory `public`, Node.js 24. Сборка не нужна. Отзывы/гарантии и цены заменяются реальными данными перед использованием. SEO: title/description/Open Graph, русская семантическая разметка, favicon. После подключения окончательного домена задайте canonical, sitemap и реальную LocalBusiness-разметку. Не создавайте фиктивную бизнес-разметку для портфолио.
